# Superman releases

Public downloads and update files for **Superman**, an alpha desktop app by The Social Algorithm.
The source code is private; this repository only holds installers, update manifests and release notes.

**Alpha software.** Read the release notes and the in-app terms before using it.
Installers are not signed by Apple or Microsoft yet, so your computer will warn you the first time;
each release explains the one-time "Open Anyway" step.
